# SVCPlatform

**Ядро для запуска сервисов соответствующих svc стандарту (svc стандарт - `svc` в названиях репозиториев)**

### url для установки пакета (прописать в pyproject.toml целевого проекта)

```text
"svc_platform @ git+https://github.com/Mike2024New/svc_platform.git"
```

---

## SVC стандарт:

```text
SVC стандарт имеет cli методы:
------------------------------------------------------------------------------------------------------------------
I. Редактирование настроек:

settings-show  Просмотр текущих настроек                                                                                                                          │
               Примеры команд:                                                                                                                                    │
                   settings-show                                                                                                                                  │
settings-edit  Обновление настроек (работает для плоской архитектуры ключ-значение)                                                                               │
               Парсит значения из строк (например 512 будет определено как int, что корректно для моделей pydantic)                                               │
               Примеры команд:                                                                                                                                    │
                   settings-edit samplerate=32000 blocksize=512 name=test  

------------------------------------------------------------------------------------------------------------------
II. Управление сервером:

 run-server     Запуск сервера с полезной нагрузкой.                                                                                                               │
                Сервер имеет базовые эндпоинты:                                                                                                                    │
                    /health/      - проверка состояния сервера                                                                                                     │
                    /parameters/  - параметры текущего компонента                                                                                                  │
                    /pid/         - pid сервера, для принудительной остановки в случае отключения терминала                                                        │
                    /shutdown/    - штатное завершение работы сервера                                                                                              │
                Опции:                                                                                                                                             │
                    -p (--port)         - порт на котором будет запущен сервер (по умолчанию 8000)                                                                 │
                    -ll (--log-level)   - минимальный уровень логирования ('debug', 'info', 'warning', 'error')                                                    │
                Примеры команд:                                                                                                                                    │
                    run-server            - с параметрами по умолчанию                                                                                             │
                    run-server -p 8000    - с указанием порта                                                                                                      │
                    run-server -ll info   - с минимальным уровнем логирования info
                     
-------------------------------------------------------------------------------------------------------------------

Запущенный SVC сервер имеет api (на примере host=`'localhost'`, port=`8000`):

[get] http://localhost:8000/health/ - проверка состояния сервера, статус компонента (запущен/остановлен)
[get] http://localhost:8000/parameters/ - расширенные параметры Engine (версия модели, устройство, настройки)
[get] http://localhost:8000/start/ - запуск компонента внутри сервера (например whisper с тяжелой нагрузкой)
[get] http://localhost:8000/stop/ - остановка компонента внутри сервера (выгрузка ресурсов)
[post] http://localhost:8000/execute/ - отправка данных на сервер и выполнение действий компонентом сервера без ответа (исполнение например tts произносит речь).
[post] http://localhost:8000/process/ - отправка данных на сервер и выполнение вычислений с последующей выдачей результата.
[stream] ws://localhost:8000/ws  - отправка данных на сервер и подключение к серверу в режиме стриминга и получение потока данных в реальном времени.

[get] http://localhost:8000/shutdown/ - завершение работы сервера.
```

---

## Как создать сервис на базе SVCPlatform

1. Наследовать `Engine` и переопределить `_on_start`, `_on_process`, `_on_stream`
2. Собрать в `cli.py` через `api_factory`, `server_factory`, `cli_factory`
3. `python cli.py run-server`

Готово — Whisper/TTS/LLM сервис работает по SVC стандарту.
